# MangaForge Design System

Bem-vindo ao design system do **MangaForge** — uma aplicação web para converter mangás online em formatos compatíveis com Kindle.

## Sobre

O design system é inspirado em **quadrinhos e pop art**, com:

- **Bordas grossas** (3px sólidas) em todos os componentes
- **Sombras duras** (hard offset shadows) sem blur
- **Cores vibrantes** — amarelo, vermelho, azul e creme
- **Tipografia display** (Bangers) para títulos
- **Animações cômicas** — pop, shake, halftone

## Design Tokens

| Token | Uso |
|---|---|
| `--comic-yellow` | Backgrounds de destaque, badges |
| `--comic-red` | Botões primários, alertas de erro |
| `--comic-blue` | Links, progresso, info |
| `--comic-cream` | Background da página |
| `--comic-ink` | Texto, bordas |
| `--shadow-comic-sm` | Cards pequenos |
| `--shadow-comic` | Botões, elementos interativos |
| `--shadow-comic-lg` | Modais, popups |
